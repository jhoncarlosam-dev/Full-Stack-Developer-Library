# Biblioteca de contingencia full stack

Biblioteca práctica, en español, alineada al [Full Stack Roadmap](https://roadmap.sh/full-stack) de 2026. Sirve para construir una aplicación web y resolver los fallos habituales sin depender de una IA.

Stack único: HTML, CSS, JavaScript, Tailwind, React, npm, Git, GitHub, Node.js, PostgreSQL, API REST, Redis, JWT, Linux, AWS básico, Monit, GitHub Actions, Ansible y Terraform.

## Cómo usarla

- En el navegador: abre `abrir.html` (en GitHub Pages, la raíz ya entra ahí).
- En el editor: empieza por [LEEME.md](LEEME.md). Si tienes un error, busca el texto literal en [00-indice-de-sintomas.md](00-indice-de-sintomas.md).

Cada tema tiene tres niveles: básico (funciona en tu máquina), intermedio (app pequeña) y avanzado (lo que se rompe con usuarios reales).

Si editas un markdown, regenera el visor:

```bash
node construir-visor.js
```
